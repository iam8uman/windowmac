The Mac keyboard shortcuts you need most for windows are **Command-Tab** to switch apps, **Command-`** to switch windows of the same app, **Command-H** to hide, **Command-M** to minimise, **Command-W** to close and **Control-Up Arrow** for Mission Control. On macOS Sequoia 15 or later, **Fn-Control** plus an arrow key tiles a window to half the screen.

Below is the full set, grouped by what you are trying to do, with notes on the behaviour that catches people out.

## How do I switch between apps and windows with the keyboard?

| Shortcut | What it does |
| --- | --- |
| <kbd>Command</kbd>-<kbd>Tab</kbd> | Switch to the app you used last |
| Hold <kbd>Command</kbd>, tap <kbd>Tab</kbd> repeatedly | Step through open apps, release to switch |
| <kbd>Command</kbd>-<kbd>`</kbd> | Next window of the current app |
| <kbd>Shift</kbd>-<kbd>Command</kbd>-<kbd>`</kbd> | Previous window of the current app |
| <kbd>Control</kbd>-<kbd>F4</kbd> | Move focus to the active or next window |

A few details make the app switcher more useful. While holding Command in the switcher you can use the arrow keys to move through the apps, and pressing **Esc** or the **full stop (period)** key before you let go cancels it. Command-Tab switches apps, not windows, which is why Command-` matters: if you have three Safari windows, Command-Tab gets you to Safari and Command-` cycles through its windows.

## How do I hide, minimise, close or quit with the keyboard?

These four look similar but do different things. Hiding is usually the fastest way to clear clutter because the app's windows come back exactly as they were.

| Shortcut | What it does |
| --- | --- |
| <kbd>Command</kbd>-<kbd>H</kbd> | Hide all windows of the front app |
| <kbd>Option</kbd>-<kbd>Command</kbd>-<kbd>H</kbd> | Show the front app, hide every other app |
| <kbd>Command</kbd>-<kbd>M</kbd> | Minimise the front window to the Dock |
| <kbd>Option</kbd>-<kbd>Command</kbd>-<kbd>M</kbd> | Minimise all windows of the front app |
| <kbd>Command</kbd>-<kbd>W</kbd> | Close the front window |
| <kbd>Option</kbd>-<kbd>Command</kbd>-<kbd>W</kbd> | Close all windows of the app |
| <kbd>Command</kbd>-<kbd>Q</kbd> | Quit the app |
| <kbd>Option</kbd>-<kbd>Command</kbd>-<kbd>Esc</kbd> | Force quit an app |

Closing a window does not quit the app. Apple points out that after Option-Command-W the app stays open, shown by a dot under its Dock icon.

## What are the shortcuts for full screen and tiling?

| Shortcut | What it does |
| --- | --- |
| <kbd>Control</kbd>-<kbd>Command</kbd>-<kbd>F</kbd> | Enter or leave full screen, if the app supports it |
| <kbd>Fn</kbd>-<kbd>Control</kbd>-<kbd>F</kbd> | Fill the desktop without full screen (macOS 15+) |
| <kbd>Fn</kbd>-<kbd>Control</kbd>-<kbd>←</kbd> / <kbd>→</kbd> | Left or right half (macOS 15+) |
| <kbd>Fn</kbd>-<kbd>Control</kbd>-<kbd>C</kbd> | Centre the window (macOS 15+) |
| <kbd>Fn</kbd>-<kbd>Control</kbd>-<kbd>R</kbd> | Return to the size before tiling (macOS 15+) |

Full screen moves the app into its own space and hides the menu bar and Dock; filling keeps them. There are more tiling combinations for two and three windows, all listed in our guide to [macOS window tiling shortcuts](/blog/macos-window-tiling-shortcuts/).

## What are the Mission Control and Spaces shortcuts?

| Shortcut | What it does |
| --- | --- |
| <kbd>Control</kbd>-<kbd>↑</kbd> or the Mission Control key | Open Mission Control |
| <kbd>Control</kbd>-<kbd>↓</kbd> | Show all windows of the front app |
| <kbd>Control</kbd>-<kbd>←</kbd> / <kbd>→</kbd> | Move to the previous or next desktop space |
| <kbd>Command</kbd>-Mission Control, <kbd>Fn</kbd>-<kbd>H</kbd> or <kbd>Fn</kbd>-<kbd>F11</kbd> | Show the desktop |
| <kbd>Option</kbd>-Mission Control | Open Mission Control settings |
| <kbd>Option</kbd>-<kbd>Command</kbd>-<kbd>D</kbd> or <kbd>Fn</kbd>-<kbd>A</kbd> | Show or hide the Dock |

If you use desktop spaces a lot, our [Mission Control guide](/blog/mission-control-mac/) explains what each view shows and how to tune it.

## What window jobs have no built-in shortcut?

macOS covers switching and hiding well, but some everyday jobs have no key at all:

- **Moving a window to another display.** You have to drag it.
- **Quarters, thirds and two thirds.** Quarters are in the Window menu without a key; thirds do not exist.
- **Nudging or growing a window** a little at a time.
- **Undoing a move** beyond the single Return to Previous Size.

A window manager fills these. In [Windowmac](/), hold **Option** and press <kbd>[</kbd> or <kbd>]</kbd> to send the window to the previous or next screen, <kbd>1</kbd> to <kbd>4</kbd> for quarters, an arrow key twice for a third, <kbd>=</kbd> or <kbd>-</kbd> to grow or shrink, and <kbd>Z</kbd> to undo. Because they only work while Option is held, normal typing is not affected.

| If you only learn five | Why |
| --- | --- |
| <kbd>Command</kbd>-<kbd>Tab</kbd> | Fastest way between apps |
| <kbd>Command</kbd>-<kbd>`</kbd> | Between windows of one app |
| <kbd>Option</kbd>-<kbd>Command</kbd>-<kbd>H</kbd> | Instant focus on one app |
| <kbd>Control</kbd>-<kbd>↑</kbd> | See everything at once |
| <kbd>Fn</kbd>-<kbd>Control</kbd>-<kbd>←</kbd> / <kbd>→</kbd> | Side-by-side windows |
